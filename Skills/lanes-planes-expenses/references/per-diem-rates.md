# German Per Diem Rates (Mehrkostenpauschale)

## Standard Rates (2024)

**Domestic (Germany):**
- Full day (≥24 hours): €28
- Partial day (8-24 hours): €14
- Arrival/Departure day: €14 each

**International:**
- Rates vary by country
- Check official BMF list if needed
- Default to domestic rates unless specified

## Calculation Logic

1. Count travel days from departure to return
2. First day: €14
3. Full days in between: €28 each
4. Last day: €14
5. **Total = sum of all days**

## Example

Trip: Monday 09:00 → Wednesday 18:00
- Monday (arrival): €14
- Tuesday (full day): €28
- Wednesday (departure): €14
- **Total: €56**

## Meal Deductions

**Default assumption: NO meal deductions** unless Robin-Manuel specifies otherwise.

Common deductions (if ever needed):
- Breakfast provided: -20% of daily rate
- Lunch provided: -40% of daily rate
- Dinner provided: -40% of daily rate
